# Travelaya
Travelaya helps tourists select the best place of interest from a wide range of choices and provide the best traveling services to our beloved customers. Find yourself immersed in local and international scenes anywhere, anytime.

This website is developed for our Human Computer Interaction course.

## Project Structure
```
project/
├── index.html
├── places.html
├── booking.html
├── styles.css
├── data.js
├── views.js
└── app.js
```

## Features
- Selection of place of interest
- Provision of tour packages
- Reservation
- UX-friendly billing and payment
