# Travelaya
Travelaya helps tourists select the best place of interest from a wide range of choices and provide the best traveling services to our beloved customers. Find yourself immersed in local and international scenes anywhere, anytime.

This website is developed for our Human Computer Interaction course.

## Project Structure
```
project/
├── index.html
├── styles.css
├── mobile-hci.css
├── chatbot.css
├── chatbot.js
├── cloud.js
├── config.js
├── data.js
├── views.js
└── app.js
```

## Features
- Diverse selection of place of interests
- Tour packages that shows destinations and its inclusions
- Selection of itineraries
- Easy reservation, with support for billing and payment
- Chatbot that answers common questions and suggests trips
